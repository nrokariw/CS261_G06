# ระบบยืมของระหว่างนักศึกษาภายในมหาวิทยาลัย

สร้างสังคมการแบ่งปันภายในมหาวิทยาลัยที่นักศึกษาหรือบุคลากรในมหาวิทยาลัยที่ผู้ใช้สามารถเข้าถึง สิ่งของเครื่องใช้ต่างๆ ผ่านการยืมของจากนักศึกษา หรือบุคลากรคนอื่นๆ ในมหาวิทยาลัยเพื่อลดค่าใช้จ่าย และลดการซื้อของที่ไม่ได้ใช้งานบ่อย
